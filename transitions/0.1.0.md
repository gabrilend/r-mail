# rmail 0.1.0 — the first version with a number

**What was built.**  rmail now knows which version it is.  `rmail.lua
--version` says so, a running mailbox writes the version it runs to
`.state/version` and logs it when it starts, and
`scripts/rmail-monitor.lua` lists the mailboxes on a machine with their
ports, whether each is running, and the version each runs (#713).

**Why.**  A machine can hold several mailboxes, each its own service
(#613), and until now nothing could say which ones it had or whether a
mailbox was still running an old program after the checkout moved on.
Every version from here on gets a chapter in `transitions/`, so when a
mailbox moves past the version the monitor last saw, it can point at
the story of what changed.

**How.**  The number is a line in `rmail.lua`, raised by hand when a
change is worth a chapter.  The monitor reads it from the file rather
than running the program, and finds mailboxes in the service files
`install.sh` writes and in the processes running now.  A mailbox whose
config says `monitor = no` is left out.

**Before this.**  Everything earlier has no number.  Its story is in
`issues/completed/`, one issue per change, and in the conversations it
was built in, under `llm-transcripts/`.
