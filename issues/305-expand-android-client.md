# Expand Android client (collected ideas)

## Sync error display
- Don't clear the connection error banner when a sync attempt starts
- Only clear it when a sync actually succeeds
- Currently: error clears on sync start → user sees it flash away and
  come back if the sync fails again, which is confusing
- Should be: error stays visible until a successful sync replaces it
